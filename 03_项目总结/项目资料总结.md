# 内镜中心VR监督检查项目：资料总结

整理日期：2026-09-15。

## 一、项目整体判断

这组资料指向一个以医疗机构疾控监督检查为主题的VR教学项目：学习者按内镜中心检查路线观察环境、设备、物品与记录，学习检查方法，并通过预设问题进行找错考核。清洗消毒室是拍摄脚本明确的核心场景。

资料已经提供业务检查框架、五场景拍摄路线、一份清洗室三维模型及四张设备细节照片，可作为需求梳理和场景设计的起点。尚不足以直接形成完整的考核题库或可运行VR成品。

证据层级：以下分别标注“指南内容”“脚本要求”“照片观察”“模型检查”和“整理建议”。本总结归纳用户提供的版本，未联网核验法规、标准的现行有效性，也未据照片对现场作合规判定。

### 指南总体结构

指南共九章：预防接种管理、传染病疫情报告、传染病疫情控制、消毒隔离、医疗废物处置、病原微生物实验室生物安全管理、职业健康检查、职业病诊断、放射卫生。

本项目直接相关的是第四章“消毒隔离”第三节“内镜诊疗中心（室）”：**印刷页102–116，对应PDF第105–119页**。其中检查表位于PDF第105–106页，流程图位于第107页，检查方法及依据位于第108–119页。以下页码均指PDF页码。

## 三、指南中与项目直接相关的检查内容

内镜章节分为7组指标，共28个检查子项。

| 检查组 | 核心内容（指南摘要） | 主要证据形式 | 页码 |
|---|---|---|---|
| 1. 布局及设施设备 | 办公、候诊、诊疗、清洗消毒、储存区域设置；不同系统诊疗分开；洗消室与诊疗室分开；特定灭菌内镜诊疗环境要求 | 空间全景、实体隔断、房间用途、环境监测记录 | 108–109 |
| 2. 内镜及附件数量 | 数量与接诊量相适应，诊疗例数与洗消时间相关性合理 | 内镜清单、接诊数据、时间记录交叉核查 | 109–110 |
| 3. 一人一用一消毒 | 每次使用后彻底清洗并按适用情形高水平消毒或灭菌；区分接触完整黏膜与进入无菌组织等情形 | 操作观察、产品说明书、使用和处理记录 | 110–111 |
| 4. 用后立即清洗消毒或灭菌 | 不同系统洗消设备分开；清洗、漂洗、消毒、终末漂洗、干燥工位齐备且流线无回流交叉；工具、储存、供水和消毒产品要求 | 工位及工具观察、供水资料、产品索证、储存清洁记录 | 112–114 |
| 5. 清洗消毒灭菌记录 | 患者与内镜关联、起止时间、操作人员信息完整；测漏记录；当日首次使用前处理记录 | 追溯系统和纸质台账 | 114–115 |
| 6. 消毒相关监测 | 清洗质量、消毒剂浓度和染菌量、内镜生物学监测、消毒机新装/维修后监测、手和环境监测、资料保存 | 检测报告、频次核查、不合格处置及复检证据 | 115–118 |
| 7. 工作人员 | 岗位培训、继续教育、标准预防、清洗消毒人员防护用品配置及穿戴 | 培训资料、用品配置、人员实际操作 | 118–119 |

### 适合转化为台账核查题的明确条件

以下均为所提供指南的表述摘要，供后续编写题目时回查原文：

- 储存柜每周清洁消毒1次（第113页）。
- 清洗消毒记录包含诊疗日期、患者标识、内镜编号、清洗消毒起止时间和操作人员姓名（第114页）。
- 对当日使用的软式内镜，核查每日使用后至少测漏1次及相应记录（第114–115页）。
- 每日诊疗前，当日拟使用的消毒类内镜再次消毒、终末漂洗、干燥后使用（第115页）。
- 一次性使用的消毒剂、灭菌剂每批次监测浓度；重复使用者每次使用前监测浓度；染菌量每季度监测1次（第116页）。
- 消毒后内镜每季度生物学监测；按不少于25%轮换抽检，每次数量不少于5条，总数少于5条时每次全部监测（第116页）。
- 内镜清洗消毒机新安装或维修后，应有相应生物学监测合格证据（第117页）。
- 每季度开展医务人员手消毒效果及诊疗室、清洗消毒室环境消毒效果监测（第117–118页）。
- 消毒剂浓度监测资料保存六个月以上，其他监测资料保存三年以上（第118页）。

消毒时间、浓度等题目应绑定具体产品说明书和适用情形。现有照片中的控制面板读数不能直接作为统一的合格阈值。

## 四、拍摄脚本总结

### 明确的制作设定

- 用于VR教学培训，全程无人物出镜，仅展示环境、设备、台账及物品。
- 运用全景、中景、特写与转场运镜。
- 路线：办公室 → 内镜及附件储存库（柜） → 候诊室 → 内镜诊疗室 → 清洗消毒室 → 回办公室文书汇总。
- 建议形成合规教学素材和预埋风险找错素材两套版本。

### 五场景内容与素材覆盖

| 场景 | 编号镜头数 | 脚本内容 | 当前可用素材 |
|---|---:|---|---|
| 办公室 | 4 | 办公环境、纸质台账、追溯系统、消毒产品档案 | 指南和文字脚本；缺少现场照片、示例台账和系统界面 |
| 储存库（柜） | 3 | 柜体及内镜悬挂、每周清洁记录、镜体洁净度 | 文字脚本；干燥台照片不能替代储存柜资料 |
| 候诊室 | 1 | 座椅、通道、隔断与流线 | 文字脚本；缺少平面图和空间照片 |
| 诊疗室 | 4 | 不同系统分室、环境报告、历史诊疗及消毒时长数据、物品及废物桶 | 文字脚本；缺少诊疗设备及房间资料 |
| 清洗消毒室 | 6 | 全室布局及槽位、清洗工具、供水滤膜、消毒剂、灭菌附件包装、测漏设备及记录 | 4张局部照片、1份待视觉验证的FBX模型 |

脚本开头提出“回办公室文书汇总”，但正文没有独立的汇总镜头清单；风险版也尚未逐项定义问题、正确答案和评分逻辑。

## 六、FBX模型检查结果

已读取二进制文件结构并统计对象和数组，未导入三维引擎、未渲染模型、未测量运行帧率。

| 项目 | 结果 |
|---|---|
| 格式 | Kaydara FBX Binary，版本7400 |
| 文件大小 | 75,104,240字节，约71.6 MiB |
| Geometry | 129个，结构属性为Mesh |
| Model节点 | 153个 |
| Material | 56个 |
| Texture / Video | 各8个对象；对象存在不等于贴图文件齐全或可用 |
| 顶点坐标数组 | 3,217,656个分量，即1,072,552个XYZ顶点条目 |
| 多边形索引数组 | 4,270,878个索引条目；不是三角形数量 |
| 坐标/单位元数据 | UpAxis=1、UpAxisSign=1、UnitScaleFactor=100，导入时应核对尺度及朝向 |

整理判断：模型几何规模较大，应先检查贴图、实际尺寸、对象拆分、碰撞与材质，再结合最终平台决定优化方案。不能据文件大小或顶点数量直接断言能否在特定VR设备流畅运行。具体是否采用Quest 3、Unity、Unreal、WebXR或全景VR，现有资料尚未明确。

详细机器可读结果见 `02_资料提取/模型结构检查.json`。

## 七、脚本与指南需要对齐的地方

| 问题 | 资料对照 | 整理建议 |
|---|---|---|
| 测漏频次表述不同 | 脚本写“每一次使用均留有记录”；指南指标为每日使用后至少测漏1次 | 区分脚本演示要求与指南检查口径，正式评分前统一表述 |
| 候诊隔断条件 | 脚本写候诊区与诊疗通道实体隔断、人流互不交叉；本次内镜章节对应候诊检查点主要为布局合理性 | 不直接把脚本这一描述变成该章节的强制扣分项，需补充具体依据 |
| 无人物与人员考核 | 脚本要求全程无人；指南含实际穿戴、操作、知识技能检查 | 静态展示可覆盖防护用品配置和培训档案，不能证明实际穿戴与操作正确 |
| 风险版尚未成题 | 当前逐镜头描述主要是合规画面 | 建立“风险状态—证据—答案—依据—反馈—评分”表 |
| 清洗消毒设备清单不完整 | 指南还列出超声清洗器、内镜及附件运送容器等；工具特写清单未全部列明 | 增补道具表，并核对模型是否已有这些对象 |
| 监测报告“有效期” | 脚本使用概括性表述，指南更强调监测频次、抽检数量、结果和不合格闭环 | 题目展示采样日期、监测对象、频次及处置证据，避免仅凭“有效”标签判断 |
| 储存柜描述 | 脚本写“密闭通风”，指南分别描述储存柜表面易清洁、干燥及储存库通风干燥 | 分开描述柜体与房间条件，防止视觉设计含混 |
| 供水与附件分类 | 脚本使用“纯化水”“宫腔镜类内镜附件”等简写 | 按指南、产品说明书和具体器械用途明确处理方式与判定条件 |

以下为整理建议，不是用户已确认的开发需求。

1. 五个区域的平面图、尺寸、门与隔断位置、完整工位顺序及流线照片。
2. FBX预览、贴图文件或贴图打包说明、模型单位及对象清单。
