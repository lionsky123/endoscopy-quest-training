# Arrival event audio

These are independently triggered short clips, not a fixed soundtrack. Wake is a trim of the approved Meta The World Beyond MT_Flashlight_Flicker sample. Step is a trimmed mono version of KenneyGrassContact (CC0; parent LICENSE-Kenney-ImpactSounds.txt).
Crack, Recoil, Connect, Appear, Cross and Close are short, faded/normalized edits of the existing project-owned PortalGathering and CrossingImpact source renders. The latter source files remain authoring inputs, no longer configured for runtime playback. Recoil and Close use reversed excerpts. This is a first event mix, not a claim that downloaded commercial sound libraries were licensed or integrated.
No WOW trial audio or Zap package audio is included. Exact edit recipe is preserved with the execution evidence at `D:/work/un/BGQR-OpeningExecution-20260911/prepare-event-audio.py`.


Reproduction: trim at source sample rate, average channels, reverse only where marked, apply 18 ms linear fades at both ends, normalize peak to 0.78, save PCM16 mono.
