# 0.7.0：双手操作与关卡教学

> 历史版本说明，当前入口与操作以 [0.8.0 手部动作说明](HANDS_ON_RELEASE.md) 为准。旧版鼠标、手柄、声音或答题主流程不再适用于当前默认体验。

本版根据用户最新要求调整：裸手操作（包括面板）、暂不播放语音、明确新手引导、保留原房间模型，以关卡资料承载细节。此说明覆盖旧版手柄、语音和改造设备的操作说明。

## 用户实际怎么操作

1. 在 Quest 系统中开启手部追踪，放下手柄，让头显看到双手。
2. 开场伸出食指触碰绿色练习按钮；按钮靠近时变亮。
3. 收回手指，再触碰“我会触碰了”，进入第一关。
4. 每步固定为：查看本题资料 → 做判断 → 看解释 → 主动继续。翻页、图片放大/平移、答案和模式按钮均采用食指触碰。
5. 真实走动、转身仍由头显追踪。关卡内无摇杆、WASD、自动行走；继续下一步保留实际位置，将资料放到面前。重新开始一轮才重置初始观察位。

操作只有一种，不要求记扳机、侧握、X/A/B 或组合手势。新页面有短暂防误触时间；手指必须先在按钮前方，再向前触碰。追踪丢失会取消预备触碰状态，重新出现的手不会直接触发按钮。

## 模型和六关如何分工

运行时直接加载原清洗室转换资产；不再调用旧 ClinicalWorld 的设备替换、柜台/工具生成和风险几何改造。房间提供空间背景与真实走动体验，不以模型变化暗示考核答案。

| 关卡 | 核查内容 | 本版呈现 |
|---|---|---|
| 1 布局与流程 | 隔断/门、设备分设、五环节单向流程 | 原房间背景＋文字案例；保留3个子任务 |
| 2 清洗工具 | 五类工具、毛刷完整性 | 用户清洗/测漏照片＋案例；保留2个子任务 |
| 3 供水与滤膜 | 供水及维护、更换记录 | 标明“教学模拟”的记录；保留2个子任务 |
| 4 消毒产品 | 标签/说明书、参数依据 | 公开产品标签与说明书扫描，可触碰放大/平移 |
| 5 灭菌附件包装 | 灭菌方式、包装与记录 | 标明“教学模拟”的包装/处理记录，不再要求打开粗糙盒盖 |
| 6 测漏与逐次记录 | 使用清单与每次测漏对应 | 用户测漏局部照片＋模拟使用清单/测漏登记比对；保留2个子任务 |

合计仍为六组、11项检查，教学重试、三种考核情境与结果汇总保留。资料开头明确说明：本题案例不代表眼前模型实际状态。照片按已有来源使用，不伪装成所有条件均已实拍。

## 技术与验证范围

- Unity XR Hands 1.7.2，OpenXR Hand Tracking Subsystem；启用 Quest 手部追踪，关闭 Touch Controller Profile。
- 双手模型使用 Unity 官方 HandVisualizer 的左右手 FBX/骨架和追踪组件，保留许可；不是旧版固定手形示意模型。
- Android 构建声明手部追踪为必需功能。无语音 AudioSource，旧语音源文件暂保留，但本版不播放。
- 桌面鼠标仅用于开发预览；自动流程验证不能替代真实头显追踪、触碰距离、遮挡及帧率测试。
- 当前仍缺毛刷破损、滤膜、灭菌附件包装等专业实拍特写；当前案例教学不等于甲方全部视觉要求已验收。
