# Unity 房间模型编辑窗口

Unity 顶部菜单：`Endoscopy → 房间模型 → 打开房间编辑场景`。

场景：`app/Assets/EndoscopyTheme/RoomWorkspace/WashingRoom.unity`。
房间预制体：同目录 `WashingRoom.prefab`；网格与材质保存在 `RoomGeometry.asset`，贴图沿用原房间资源。

无需 Play，Scene 窗口直接显示完整清洗消毒室。左侧展开“清洗消毒室”可选择模型部件；W 移动、E 旋转、R 缩放，Ctrl+S 保存。场景带室内查看相机与灯光，无音频、XR 或教学流程组件。

视角找不到时，使用 `Endoscopy → 房间模型 → 回到室内视角`。返回正式流程使用同菜单的“返回主体验场景”。再次打开已有房间场景不会重新生成或覆盖摆放修改。

这是独立的房间编辑副本，未加入构建场景。此处模型变换尚未接入正式 VR 房间加载器；也没有导出地图站点或路线的功能。因此保存不会自动修改 Quest 主体验的模型和站点。正式运行仍使用原房间资源与已发布地图。

2026-09-18：已在当前 Android 目标 Unity 编辑器导入工具并实际打开场景，确认 129 个网格及材质可见；未构建、安装或启动 Quest 应用。
