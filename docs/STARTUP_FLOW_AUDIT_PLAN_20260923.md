### 分幕体验设计与实施顺序（2026-09-23）

依据：[spec第7.2节](FULL_SCRIPT_SPEC_20260920.md#72-分幕式引导探索规格2026-09-23访谈确认)。本次只制定设计/计划与预制媒体，未改运行代码、未启动Unity。E编号是原M/C任务内的切片，上方复选框是唯一完成状态；原M1–M4及C02–C10业务缺口不因本设计取消。

**设计决定。** 大厅是游戏式章节选择背景，不是可选关卡；主题/检查点选择仅在当前业务房间显示。建议初版同屏最多3个主要入口，超过时按有业务含义的主题组织；这是待坐站验证的设计起点，不是减少内容的上限。推荐入口突出一个动作，回查/返回为次要操作。首次开始衔接办公室，不人为增加选择确认。储存库样板验证时走正常主线路线或编辑器测试夹具，不在正式入口增加“跳到储存库”调试按钮。

**画面与节奏。** 浅色低反光表面、深色正文、克制青色选中反馈；字体/圆角/状态复用并统一现有ClinicalPanelStyle与VisitorCoachTheme。对话紧凑且可收起，资料保留表格与载体，现场观察仅留低位操作。大厅按正式流程呈现“开始学习”及当前可用目的地，不保留旧章节概念布局；实际角色、文本与入口须在Unity同一视野内核对。过渡时长与弧角不在平面图中硬编码，沿可靠追踪/释放屏障调节，不能靠延时绕过就绪条件。

**依赖与顺序。** M5.E01 → M5.E02 → C01.E01；M5.E03依赖E01/E02；C05.E01可在对话和样式完成后进行；C03.E01依赖E03及样式。上述形成M5.K1样板。随后C11.E01 → C11.E02建立教学事实与提示重试，再推广C03.E02、C04.E01、C05.E02、C06.E01→E02、C07.E01→E03、C08.E01→E02、C09.E01、C10.E01；最终C11.E03 → M5.K2 → M5.K3。原C项的对象/证据缺件始终是对应完整验收的前置条件。高风险的追踪、回查主线位置、界面互斥先在样板暴露，不最后才验证。
