# 0.5.0：现场交互与资源替换

> 历史版本说明，当前入口与操作以 [0.8.0 手部动作说明](HANDS_ON_RELEASE.md) 为准。旧版鼠标、手柄、声音或答题主流程不再适用于当前默认体验。

## 本轮要求

参考本机 D:\unity\Unity-FirstHand-main，减少面板，用物件交互和现场引导组织体验，优先采用有明确授权的网络资源。范围仍为清洗消毒室11项监督检查。

## 已实现

1. 启动直接进入引导学习，取消首页大面板和常驻腕部任务卡。拿起物品或选择工位不会自动打开资料。
2. 左摇杆行走、右摇杆30度转向。地面路线带到当前工位，局部短提示说明下一步；短时字幕5秒后消失。
3. 可拿取物件使用近距离侧握抓取。教学中持续持物1.5秒并转动至少15度后记录完成；固定对象需先选择，再近距离观察至少1.5秒。
4. 长记录放在主动打开的实体检查夹中。按左X，或持物按扳机查阅；翻完全部页面后收起才记为已读。中途切换资料或取消不记为读完。
5. 检查夹支持右手柄前端触碰翻页、收起按钮，也保留射线点击。当前使用Touch手柄，尚未接入裸手追踪。
6. 自主检查：右A记录正常；右B循环问题原因，再按A确认。重新选择对象可取消原因选择。未查阅的记录、未拿起转动的工具不能直接作答。
7. 靠近可拿取物件后8秒未推进，短暂出现半透明手部示范；每30秒最多显示6秒。它是位置/接近动作提示，不是追踪手或完整手指抓握动画。
8. 检查夹“开始/切换”按引导学习→自主情境1→2→3循环，每次切换清空本次会话。完成后走到入口记录台汇总或提交。

## 与First Hand的关系

参考其PromptTutorialHandler、AnimatedGhostHand、SubtitleHints的分步提示与动作推进思路。没有迁移完整工程或Meta Interaction SDK依赖；现工程保持Unity 6000.3.23f1、OpenXR与XRI，避免混入参考工程的Unity 2022.3设置。

仅复用该项目MIT许可下的参考手模型与完成音效，许可证随资源保存。来源见 [网络资源与许可](WEB_ASSET_SOURCES.md)。

## 实际边界

- 本轮是监督检查、拿取观察与记录判断，没有新增配液、刷洗或完整临床消毒操作模拟。
- 临床判定仍来自原项目资料和既定教学产品文件。网络通用容器只承担外观，不代表真实消毒剂包装或器械兼容性。
- 毛刷、水气枪、测漏仪等仍有简化资产，未标记为美术验收完成。
- 自动巡检检查路由、碰撞、资料状态与评分；Touch拿取手感、触碰翻页、双眼可读性和帧率等待用户自行佩戴验证。
