## 启动与平台框架

1. 应用加载后，首个可交互环境就是完整三维清洗消毒室，邀请和小精灵登场在房间内进行。系统加载背景为黑色，应用相机背景不透明。
2. Visitor 启用 `VirtualRoomEnabled`；关闭其 Passthrough、MRUK、QR 场景追踪、空间权限门控及真实空间锚点增强。VR 分支不请求这些权限，也不把未授权权限伪装成已授权。
3. 用户无需先扫描房间、授权 Scene/Anchor 或进入管理员标定页。主场景关闭旧模式切换入口；构建场景只启用 Visitor，保留 Admin 源文件供历史参考。
4. 保持现有 Meta Quest profile、Android、OpenXR、Composition Layers Support 和真实手部追踪。房间入口前方对应模型 -X 长过道方向。按 XR floor rig 初始化房间一次，随后转头、抬头、学习和换站不会重算地图朝向或移动 XR Origin。
5. 第一关全景教学暂时隐藏实体房间渲染和碰撞；关闭全景或加载失败后恢复原房间和原坐标。学习流程不改变玩家位置。

- 面板触发时放到用户前方 0.45 m：邀请、开场/到站/出发对话、学习入口、图片继续和答题面板共用此距离。相同阅读会话内保持世界位置，状态刷新、确认反馈和翻页不按用户伸手或前倾重新定位；保留垂直偏移、字号和尺寸。学习入口不再使用旧 ViewerFront 的 1.65 m 展示距离。
- 凝视使用模板共享计时器与准星进度，确认一次只推进一步；页面、可见性或输入上下文变化取消旧进度，移开再对准后才能再次确认。手部对象操作期间暂停背景面板输入；普通面板不再同时接受拍打提交。保留手部目标的停用/失焦/暂停按压锁清理。
- 静音场景保留一个启用物体上的停用 Meta 音频房间组件，阻止 SDK 自动创建并运行原生声学组件，不恢复音频。
- 无摇杆、WASD、传送或强制移动摄像机。使用实际步行和系统边界，不隐藏系统边界。
- 取消图鉴、掌心工具/地图召唤及入册。导航自动显示，学完主动凝视确认出发。
- 第 1 关维持顺序图谱与 3 道观察题；其余五关内容保留。本次不修改学习题目来配合站位。
