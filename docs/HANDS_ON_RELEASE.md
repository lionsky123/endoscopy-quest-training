## 进入后怎么做

1. Quest 开启手部追踪，放下手柄，把手放到头显能看到的位置。
2. 进入门边观察位，按提示伸出食指触碰亮点。完成后再观察右侧隔断。
3. 遇到可拿资料，用拇指和食指在下端白色捏取点附近张开、合拢，保持捏住，拿到眼前看。
4. 需要查看背面时转动手腕。放到指定绿色框内，张开两指；放错或未完成查看不会通过。
5. 当前动作完成后，触碰下方继续按钮。跨关时先站稳，再主动触碰“到下一观察位”，画面淡出后换站。站内可以真实走动、转身。
6. 11项完成后显示记录，可以重新体验，也可以进入可选案例判断考核。

当前动作提示始终保留；未检测到手时显示恢复追踪提示。按钮靠近变色，亮点完成变绿。没有语音、教程声音、按钮音效或环境音。

## 手部输入与误触处理

- 面板使用 `PokeOnlyButton`，屏蔽 PointerClick、PointerDown、PointerUp、Submit；默认入口不创建 EventSystem 或 GraphicRaycaster。
- 激活来自 XR Hands 食指尖的近距离接近与触碰。远处捏合、手柄射线、鼠标、键盘不会替代触碰。
- 拿取需在捏取点附近先张开两指，再合拢。拿取时同一只手暂停面板触碰，另一只手仍可操作。
- 捏取资料先移动并拿近视线区域；翻面任务另要求转动。完成查看后放入匹配目标框才通过。
- 手部追踪丢失会取消拿取并把资料放回原处，不计为成功。新页面有短暂防误触时间，需重新接近。
- 双面卡按观看方向仅显示朝向用户的一面，避免 UI 双面渲染导致镜像文字透出。

## FirstHand 参考与原模型

已阅读本机 `D:\unity\Unity-FirstHand-main` 的 `DoorKnock.cs`、`UIState.cs` 等实现，采用近距离接触、可操作状态反馈、动作事件推进的思路。本轮没有迁移 Meta Interaction SDK 或复制整个 Unity 2022 工程；现工程保持 Unity 6000.3.23f1、XR Hands/OpenXR。

## 全程静音与用户自行编译

- `ProjectSettings/AudioManager.asset` 开启 Disable Unity Audio。
- `SilentExperience` 负责运行时静音、停止并禁用场景 AudioSource，包括后加入的音源。
- 原生 Build/Build And Run 入口和项目菜单共用配置：包名 `com.endoscopy.inspection`，版本 `0.8.0` / code `9`，ARM64、IL2CPP、Linear、Vulkan、统一 ClinicalPipeline。
- Unity 工程仍为 `D:\quest3\EndoscopyBuild\app`。本轮没有构建 APK、安装或启动 Quest 应用；现存 `builds/EndoscopyInspection-Quest3.apk` 仍是旧版 0.7.0 / code 8。
