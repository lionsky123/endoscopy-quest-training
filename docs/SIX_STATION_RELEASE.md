# Quest 0.6.0：六站VR教学

> 历史版本文档。当前 0.7.0 裸手、无语音、原模型与关卡方案见 [双手关卡说明](HANDS_LEVELS_RELEASE.md)。

## 本轮实际实现

六站依次为布局与流程、清洗工具、供水与滤膜、消毒产品、灭菌附件包装、测漏与逐次记录。沿用11个核查步骤覆盖各组内容；教学采用讲解、查看证据、核查、反馈和主动继续。

- **移动**：运行入口不再绑定左右摇杆移动/转向，也不启用旧RoomWalking。站内由头显跟踪实际移动与转身；站间选择继续，短暂淡出后进入下一个观察位。转换保留当前实际头部偏移与高度。
- **第一站多观察位**：分别查看两台设备及五个工位，必须主动查看本步全部观察位后再查证据和作答。每次切换都由用户明确触发，不要求走完整个大房间。
- **语音**：离线中文合成欢迎词、11步讲解、11步反馈及考核操作提示，共24段，打包在APK中。左X重听当前讲解。语音由本机Microsoft Huihui Desktop生成。
- **工位展示**：固定在场景中、面向初始观察位置，选位时检查设备碰撞；不会跟随头部。显示当前站、步骤、操作和反馈。照片可放大、缩小和分方向平移，文字分页显示。
- **真实媒体**：3张用户现场参考照片，加2页公开产品标签/说明书扫描。照片来源按页显示；不拿合规产品图冒充风险产品D-X。
- **教学台账**：测漏清单与登记逐条对应；滤膜维护计划与完整更换台账；附件包装信息与同批次处理记录。均标为教学模拟。
- **完成条件**：阅读完整材料后才能核查，读完不自动完成；教学答错解释原因并允许重试，答对后主动继续。考核记录判断，允许当前步骤改答，最终提交后锁定。
- **物件**：保留附件盒开合、可选的近距离拿取；切站时释放并归位物件。拿取/凝视/转动角度不再自动增加学习进度。

## 头显操作

| 操作 | 方法 |
|---|---|
| 观察、走近与转身 | 本人实际移动，在自身可用范围内完成 |
| 选择按钮或对象 | 手柄指向后按扳机；部分按钮也可用右手柄前端触碰 |
| 重听讲解 | 左X，或工位“重听讲解” |
| 查看远处相关工位 | 主动选择“观察位”切换 |
| 查阅图片、说明书、记录 | 工位“查看本步证据”，翻页和放大 |
| 开附件盒 | 靠近，指向盒盖按扳机 |
| 可拿取物件 | 靠近后按住侧握键，松手归位 |
| 核查和继续 | 查看完整资料后选择“开始核查”，按反馈继续 |
| 模式 | “六站/模式”可重开教学或三个考核情境；会清空本轮记录 |

## 验证范围

测试检查六组/11步覆盖、语音/图像存在、分页门槛、错题重试、考核改答、逐次登记缺项和真实头部偏移保留。桌面自动巡检遍历教学与三个情境，检查两设备/五工位观察位、开盒、资料门槛、评分及截图。

这些自动化不模拟真实Touch硬件输入，不证明Quest双眼清晰度、触碰翻页手感、实际活动范围或帧率已通过。当前仍使用Touch手柄，未接入裸手追踪。本次构建不自动向用户头显安装。

## 素材缺口与边界

毛刷完整/破损实拍、完整五工具总览、真实供水/滤膜细节、宫腔镜附件包装及存放区照片未齐备。这些位置目前使用既有简化教学模型和明确标识的模拟资料，未宣称专业美术或甲方六组全部视觉验收完成。现有5份真实图片已接入，当前没有现成视频，也未新增视频素材。

完整资料来源见[六组方案](SIX_STATION_PROPOSAL.md)、[网络资源许可](WEB_ASSET_SOURCES.md)和artifacts/station-media-sources.json。具体房间布局语义、产品适配条件及专业图像仍需审校。本轮是监督检查教学，不包含完整洗消操作模拟。

## 源码与构建

Unity工程：D:\quest3\EndoscopyBuild\app；Unity 6000.3.23f1。入口InspectionApp负责XR装配，StationExperience负责六站流程，StationLocomotion只处理主动切站对齐，StationBoard负责工位展示。
