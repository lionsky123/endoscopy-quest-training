# C06 · 隐藏房间模型，分散为六关

2026-09-16 用户要求覆盖 C05 的桌面展台展示：隐藏房间模型，形成独立关卡，并拉开点位，位置由实现确定。

## 当前实现

- 原清洗室模型在创建时隐藏，保留资源，不显示展台底座。进入、退出全景及切换关卡均不恢复模型。
- 保留六关内容：正确示范 / 修复问答三组对照，修复关各 3、3、4 题。第一关提示已改为查看布局图谱，不再要求看展台。
- 点位由密集环形改为两排展开路线。相邻点中心间距 2.2 m（原为 0.85 m），圆半径仍为 0.28 m。光圈外缘之间约有 1.64 m 的空隙。
- 开始前展示六个位置供确认，可按玩家当前朝向重新布置。开始后仅显示当前关卡的金色光圈，前一关和后续关隐藏。
- 小精灵实际带路，玩家落后时等待。到达并站稳后才打开本关内容，完成本关后才引导下一关。按钮不传送玩家，原地不动不解锁下一关。
- 面板按抵达时玩家朝向摆放，不再朝向已移除的中央展台。
- MR、静音、真实近触手部按钮、360 全景、已修复的 Composition Layers 开关保留。

## 点位坐标

以开始布置时玩家脚下为 `(0,0)`，面前为纵向正方向，右侧为横向正方向，单位米：

| 关卡 | 横向 | 纵向 |
| --- | ---: | ---: |
| 1 | 0 | 1.2 |
| 2 | -2.2 | 1.2 |
| 3 | -2.2 | 3.4 |
| 4 | 0 | 3.4 |
| 5 | 2.2 | 3.4 |
| 6 | 2.2 | 1.2 |

路线为 `1 → 2 → 3 → 4 → 5 → 6`，连线不交叉。六圈外廓约宽 5 m、深 2.8 m；起点在第一圈外侧 1.2 m 处，现场还需容纳起步和身体空间。此版本没有自动扫描现实障碍物，预览的点位和相连路段必须在可行走空地内。
