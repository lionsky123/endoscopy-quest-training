# 清洗消毒室六组要求：实走与图文证据方案

> 历史版本文档。当前 0.7.0 裸手、无语音、原模型与关卡方案见 [双手关卡说明](HANDS_LEVELS_RELEASE.md)。

状态：用户已确认“小场地、逐站VR教学体验”方向，2026-09-15。以下站内引导与内容呈现为细化方案；现实活动区域尺寸尚未确定。本文覆盖0.5.0中摇杆移动、隐含计时完成和过短引导的设计，0.6.0已落实的部分与剩余缺口见[SIX_STATION_RELEASE.md](SIX_STATION_RELEASE.md)。

## 已明确的方向

- 保持甲方清洗消毒室六组要求，允许通过图片或视频实现特写，减少不必要的复杂模型/动作制作。
- 用户已选择逐站VR教学体验：同一清洗消毒室主题下的六个教学工位，依次进入；站内本人实际走动，站间主动切换。
- 移动采用本人实际走动与转身，取消摇杆位移。本人实际走动与虚拟空间按正常比例对应。
- 学习者必须能理解当前检查目标、应观察的细节和完成条件。
- 六组是内容组织单元，每组可以有多个核查条件；不以六道题代替全部要求。
- 下面的交互和风险例子属于制作方案，甲方没有提供逐题风险题库。

## 引导方式

进入时先给简短语音和字幕介绍：“今天检查清洗消毒室，共六站。先观察隔断与工位布局。”每站按以下顺序推进：

1. 显示当前站名和进度，语音明确指出一个对象。
2. 指定对象出现局部提示，告诉用户怎样触发特写或查阅证据。
3. 教学先解释检查依据，再要求找出对应细节或完成一次核查动作。
4. 给出与证据对应的反馈，再开放下一小步。提供“再听一遍/查看提示”。
5. 本站所有子条件完成后，才进入下一站。

保留一句当前任务；长资料仅在对应工位需要时展开，固定于场景位置，可放大或翻页。图片、文件、视频用于呈现细节，避免把全部检查重新塞入随身文字菜单。教学不再以自动凝视计时或转动物品角度直接判定理解。考核保留操作提示，隐藏答案提示。

## 第1组 / S13：布局、分设与单向流程

甲方要求：全室呈现槽、清洗消毒机、工具、管路；与诊疗室实体隔断完整、门关闭；消化与呼吸内镜槽/机分开配置；清洗→漂洗→消毒→终末漂洗→干燥齐全，单向无回流。

实现：以现有三维清洗室为主体，分别检查隔断门、两类设备组、五个工位和流向。教学按小步骤点亮对应对象；在实际工位上呈现流向说明。无需模拟内镜真实经过全部槽位，也不自动推动第一人称镜头。

交互：本人走到可达观察位置，指认隔断/设备组，再沿流程逐个识别工位；引导和说明逐项反馈。风险候选如共用、缺工位或回流必须在布局中真实可见。

素材与完成条件：已有模型可作基础，仍需逐物件核对设备用途、槽位关系与管路。只有名称牌不能证明真正分设。第1组不宜仅用一张特写替代空间关系。

## 第2组 / S14：五类工具与毛刷完好

甲方要求：毛刷、压力水枪、压力气枪、测漏仪、灌流器齐全；毛刷无破损。

实现：工位上呈现可辨认的五类工具照片总览；选择对应对象展开高清细节，毛刷提供正常/破损对照。需要时附短视频展示刷头多个角度；不要求模拟真实刷洗。

交互：教学逐一认识五类工具，再选中毛刷要检查的位置。考核从实际可见的工具缺项或刷毛缺损中定位问题。

素材与完成条件：现有照片支持部分水/气枪及测漏工位外观，尚不支持五类工具完整证据与毛刷破损对照。补全可授权高清图即可，不必先把五类器械全部精细建模。

## 第3组 / S15：供水、滤膜与更换记录

甲方要求：终末漂洗使用纯化水、滤膜完好、留存更换记录。

实现：三个关联证据依次展开——水源及到终末漂洗端的连接、滤膜实物细节、更换记录。使用真实管路照片加可核实的流向说明，或明确标为教学示意的管路图；滤膜和记录用高清图/可放大文档。

交互：先追查终末漂洗的水从哪里来，再查看滤膜状态，最后打开对应设备的更换记录。三个条件都需核查。

素材与完成条件：需要补水源至终点的关系、滤膜照片和更换台账；现有透明管照片不能证明纯化水或滤膜完好。单凭外壳照片不能证明滤膜内部完整；必要时给出适当检测/维护证据。未指定设备时不自创通用更换周期。

## 第4组 / S16：消毒产品标签、说明书与存放

甲方要求：瓶身标签完整清晰；呈现说明书与存放区；产品适配内镜、低腐蚀、高水平消毒。

实现：同一产品的标签扫描、说明书关键页、存放位置图关联展示。教学逐项解释如何从资料核查用途、消毒等级和材质相关腐蚀性；考核自行在原资料中查找。

交互：选择标签区域放大、翻阅对应说明书、找到支持用途等判断的字段。可以采用实际扫描件，不必建立精细瓶子或模拟配液。

素材与完成条件：已有公开产品资料含标签和说明书，可作候选。对低腐蚀性的证据需按说明书限定材料和适用条件核对，不能推为对所有内镜材料无腐蚀。缺存放区实景或明确标注的教学布置。通用塑料壶模型不是准确产品包装。

## 第5组 / S17：宫腔镜类附件和灭菌包装

甲方要求：存放盒内有宫腔镜类内镜附件，完成灭菌，包装标识完整规范。

实现：保留简单开盒互动，盒内关联真实附件/包装照片；选择包装即可近看标签。可用短视频显示包装两面，或两张照片切换。

交互：开盒→识别附件与包装→放大标识→对照相关处理证据核查。考核让用户定位标识不完整等可见问题。

素材与完成条件：当前四图均不足以支持宫腔镜附件灭菌包装；需补附件、包装及标签图，必要时补对应灭菌批次资料。包装上写“已灭菌”或单看指示颜色不能独立证明处理合格。无需模拟灭菌器操作或包装流程。

## 第6组 / S18：测漏设备与逐次记录

甲方要求：测漏仪摆放规整完好，每次使用均留记录。

实现：测漏仪近景图片与登记本正文；给出相同设备/时间范围的教学使用清单，与完整登记页对照。已有测漏工位照片可作外观参考，但不能据此断定设备功能正常。

交互：先观察设备，再将一次次使用与记录对应；风险例子可设计某次使用在完整登记本中缺失。缺项须通过足够完整的记录范围证明。

素材与完成条件：补清晰设备全貌/接口和成套使用清单、登记本。演示台账标为教学模拟，不包含真实患者信息；不把“逐次”变为“每天一次”。无需连接测漏仪或模拟加压。

## 制作取舍

保留：现有三维房间、本人走动、明确语音/字幕引导、物体触发、必要的开盒动作、图片放大、文件翻页、合规教学与风险找错、反馈与汇总。

优先替代：精细专用器械建模、复杂抓取物理、完整洗消动作、设备工作机理模拟，用可靠照片/扫描件/局部短视频展示原脚本要求的检查证据。网络素材需许可清楚，医疗细节需匹配对象；真实图与教学模拟记录分别标识。

视频仅在有时间变化或必须展示多个角度时采用，放在工位内固定位置播放；不通过移动整段第一人称镜头代替本人走动。

## 已确认：小场地逐站VR体验

六站分别为布局与流程、清洗工具、供水与滤膜、消毒产品、灭菌附件包装、测漏与记录。它们属于同一清洗消毒室的六组学习内容，不要求学习者在现实场地中走完整个约16米长的模型，也不要求新建六间无关房间。

每站在相应工位的观察位置开始。学习者身处三维房间，转身看环境、走近观察对象、选择局部照片或阅读对应记录。特写图片和视频附着于该工位的展示位置，展开时保留周围空间关系；不默认改为覆盖全部视野的视频或随头移动的大面板。

本站完成后解释结果，显示下一站名称，等待用户站稳并主动选择进入；短暂淡出，再在下一工位淡入。站内本人移动维持正常比例，摇杆位移关闭；本人转身观察，不用自动第一人称运镜连接工位。切换应对齐用户当前实际站位，不能让用户追着原始场地中心行走。

第1站保留房间全貌和空间关系，并分为隔断门、两类设备组、五工位流程三个教学小步骤。若关键细节超出本站可达范围，使用明确选择后的分观察位切换；不要求跨越现实边界走过去，也不把整个房间缩为失真的近身布景。

## 站内统一教学流程

1. 到站：语音报站名，说明本组检查目的。
2. 定向：一次指出一个对象，短字幕写清当前任务和操作方法。
3. 学习：走近或选择对象，查看对应三维细节、高清图片、扫描件或必要的短视频；可重听、重看。
4. 核查：完成与本小步内容对应的指认或判断。选错时说明原因，并允许再试。
5. 汇总：本站所有核查条件完成后给出总结，用户主动进入下一站。

考核复用同一空间与证据，只保留操作帮助和目标要求，不预先高亮问题或讲出正确答案。小步完成条件仍按甲方各子要求定义，不能用“站了几秒”或“播放结束”代替理解核查。

## 尚需落实的空间参数

实际净空长宽、障碍和舒适够取距离尚未测定，因此暂不承诺具体最小场地尺寸。工位可达对象、展示位置和站点切换对齐应按实际活动范围配置，并经佩戴验证。不得把虚拟墙体碰撞当作能阻止本人在现实中继续走动的机制。
