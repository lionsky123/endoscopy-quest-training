# 先示范检查方法，再核查不同情境

用户在教学改版访谈中选择先示范检查方法，再对未标答案的新情境独立判断。方法示范与核查题使用不同情境，题面不提前显示正误标记；提交判断后再解释依据，避免学习退化成记住刚展示的答案。

相比直接挑战再讲解，这一安排为新手提供观察方法，但需要分别准备示范和核查素材。用户进一步选择答错后先提示观察方向、再逐步增加帮助，由学习者重新判断；不以看完解析直接视为掌握。

先在第一站验证完整体验，再推广至其他站；六站共用的离站阻塞和界面堆叠先修复。该决定已进入 [有效 spec](../PANORAMA_LESSON_REDESIGN.md)，用户批准执行后的工程结果见 [实现记录](../PANORAMA_LESSON_IMPLEMENTATION.md)。
