# 房间之间允许切换，房间内部保留实际步行

2026-09-20，用户明确完整内镜中心剧本才是项目目标，C09 清洗消毒室是先期测试；并确认“房间的切换可以不靠走动，但房间内需要可以走的”。因此，完整检查路线按独立可进入的房间组织，不要求制作连接所有房间的连续可步行医院；每个房间仍须提供可实际走动的三维活动区。

这一决定把房间切换与房间内移动区分开：室内固定世界、真实手部、小精灵沿本房间路径引导继续成立，跨房间过渡允许在明确的切换阶段重新建立目的房间的进入位置。访谈进一步确认必须实际走到房门后近触门口按钮，房间总结只引导去门口；可用场地目前未定，具体活动区仍需适配，不能据此默认开放室内传送、缩放真实移动距离或用平面图替代可走房间。

相关规格：[完整剧本 spec](../FULL_SCRIPT_SPEC_20260920.md)；实施计划：[完整剧本 plan](../FULL_SCRIPT_PLAN_20260920.md)。本决定只更新目标设计，不代表运行代码已经支持多房间。
