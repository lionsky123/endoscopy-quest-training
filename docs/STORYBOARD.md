## 区域关系

办公室 → 储存库 → 候诊区 → 两间独立诊疗室 → 清洗消毒室 → 办公室汇总。

外围四区是功能性教学设计，不声称医院实测复原。洗消区采用甲方FBX，并补充脚本缺少的细节。诊疗区消化、呼吸分室；洗消区设备分设。候诊和诊疗路线用隔断、出口及地面路线表达，全程不出现人物。

转场采用用户主动进入下一站、淡出再淡入的方式，保留路线及区域名称。头显不进行强制长距离运镜。转场走廊、方向关系和视觉提示仍需在实机中核验。

## 18组分镜卡

| 镜头 | 初始观察 | 对象和特写 | 用户行为 | 结束条件 |
|---|---|---|---|---|
| S01 | 办公室入口看全室 | 两张资料桌、文件柜、电脑、打印机；文件与柜门状态 | 环视、靠近桌面和柜门 | 四类办公物件齐全且状态可辨 |
| S02 | 资料桌中景 | 六类装订记录，分页字段、镜号、日期和人员 | 选择对应实体文件、翻页放大、对照记录 | 六类文件全部可查，缺项从完整材料中成立 |
| S03 | 办公桌电脑 | 追溯记录中的患者模拟ID、镜号、起止时间、产品和人员 | 打开系统、查看完整记录 | 同一记录与纸质台账一致 |
| S04 | 产品档案所在桌面 | 产品资料目录、备案/评价材料、说明书、适用性与材料条件 | 查档案并与S16瓶签关联 | 不使用其他产品说明书替代现场产品资料 |
| S05 | 储存柜整体 | 柜门、格栅、内壁、柜底、竖直镜体 | 选择柜门开合，靠近检查柜内 | 关闭与打开状态均可看，水渍可辨 |
| S06 | 柜侧记录 | 四个完整周的清洁记录及操作人 | 选择登记本、翻页 | 可确认是否整周遗漏，不能以页面裁切制造缺项 |
| S07 | 柜门打开后 | 镜体控制部、软管表面、水渍与污渍 | 靠近镜体、选择表面证据 | 视觉污渍与记录解释一致 |
| S08 | 候诊入口全景 | 座椅、隔断、候诊出口、诊疗通道 | 沿两条可视路径观察 | 无人物也能辨认是否交叉；按脚本设计目标解释 |
| S09 | 诊疗区域入口 | 消化和呼吸房间各自的床、设备台、主机 | 分别进入两个房间、观察隔墙和用途 | 不是仅通过两块门牌表达分室 |
| S10 | 诊疗室墙边 | 空气/物表环境报告日期、场所、结果 | 打开悬挂报告，查看完整季度材料 | 条件、报告和房间对应，频次不写成虚构有效期 |
| S11 | 设备后台屏幕 | 历史镜号、开始/结束时间、产品依据和作用时长 | 逐条核对，不只查看一条代表记录 | 所有给定记录可判断，解释区分作用时间与总流程时间 |
| S12 | 诊疗工作台中景 | 器械区、耗材区、医疗废物桶盖 | 观察台面与桶盖 | 混放和开盖是真实物体状态 |
| S13 | 洗消入口全景 | 隔墙、互通门、两系统槽/消毒机、五工位、单向路线 | 环视并沿工位检查 | 门状态、设备独立性和全部流程均可见 |
| S14 | 工具台近景 | 毛刷、水枪、气枪、测漏仪、灌流器 | 看形状、接口、刷毛；核对完整配置 | 不能用五根相同柱体代替工具；缺件与全场配置一致 |
| S15 | 纯化水装置侧 | 水源→滤膜→终末漂洗连接、滤膜外壳、维护记录 | 沿水路检查并查登记 | 连接与来源标识一致，风险改变实际水管 |
| S16 | 消毒剂存放区 | 瓶签、封盖、存放条件、同产品说明书 | 查看标签和档案 | 当前产品与历史产品分日期，风险不诬指真实品牌 |
| S17 | 附件盒近景 | 宫腔镜类附件、包装、批次和处理标识 | 查看包装及同批处理/放行证据 | 附件形态可辨；不能仅以包装颜色证明灭菌 |
| S18 | 测漏设备与登记本 | 设备外壳、接口、当日完整使用清单、逐次测漏 | 核对每一次使用，并可回看办公室同源记录 | 同一镜已测一次不掩盖另一次缺记录 |

## 界面与证据

首页操作说明 → 模式/情境 → 区域观察 → 对象证据 → 标记问题或未发现问题 → 区域进度 → 最终提交 → 办公室汇总 → 分项复盘。

看过不等于已答；提交前可以改答，提交后锁定。教学说明即时可见，风险答案只在提交后出现。放大和翻页不改变记录内容。结果需区分未答、漏检、误报和原因选错。

## 仍需视觉验收的重点

柜门遮挡与打开后的观察距离；真实模型中槽位的用途映射；原始工具是否与风险配置矛盾；医疗器械外形精细度；文件文字可读性；源模型中门与补建门的位置；转场空间关系。测试通过不自动关闭这些验收项。
