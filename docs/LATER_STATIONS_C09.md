## 交互与流程

- 每关只有一个固定面板：首次显示在前方约 0.50 m、眼下 0.18 m，整体宽约 0.63 m；根据图片比例完整适配。面板正对用户后锁定世界姿态，不因选答案、答错、模型动作或宿主刷新重新定位。
- 小精灵静音字幕负责开场说明。题目中的短教程首次显示后 8 秒收起，选择后立即收起；不创建第二层教程。不同媒体复用同一内容区域。
- 判断题只显示三个选项、确认、跳过；排序题只显示工序卡、确认与跳过。所有普通按钮使用真实 Meta 手部近触，凝视不提交；模型使用 HandGrabInteractable / Grabbable，不添加手柄、鼠标或键盘入口。
- 证据页必须逐页打开后才能答对计分；未读完时明确提示继续查看。答错保留选择、显示修改依据，允许立即重试，不计分、不锁死。
- 每题可直接跳过，不需要先作答；末题跳过进入本站结果。结果分别报告答对和跳过数，用户点击返回房间后主动确认出发。没有退出答题按钮。
- 完成通知按内容会话去重，关闭成功后才发出；关闭失败可以再次操作。关闭页面本身不算完成。共用六站步行路线和主动离站，不传送玩家。
- 视频全程无音轨输出，资源本身也不含音轨。媒体缺失或解码失败保留文字情境及跳过；视频准备超过 12 秒切换到文字后备。
- 模型只是独立可抓取物体，面板不接受抓取。模型移得过远会回到展示区，用户也可使用“取回”。

## 后续换素材

配置位于 `app/Assets/EndoscopyTheme/Resources/ClinicalCourse/course.json`。每站用稳定 `sceneId` 绑定，步骤可选择 `sequence`、`image`、`video`、`model`、`evidence` 或 `ledger`。`sequence` 使用五个 `sequenceItems` 和唯一索引组成的 `sequenceOrder`；其他模式使用三个 `options` 与 `correct`。`media` 是不带扩展名的 Unity Resources 路径；`cards` 保存三份证据；`hint`、`explanation` 控制提示和解析。

新增/更换模型必须保持来源与许可，并按导入约定将视觉网格中心归零、竖直尺寸归一；碰撞与手部抓取由关卡运行时建立。当前素材转换脚本为 `tools/prepare_course_media.py`，只处理文件，不启动 Unity 或构建。
