# 清洗消毒室现场检查版 · 0.5.0

## 当前范围（用户最新确认）

暂停办公室、储存区、候诊区、诊疗室与五区转场，只开放清洗消毒室。甲方六组清洗消毒室镜头对应当前11项检查；逐次测漏登记随设备放在房间内。原始五区资料及代码保留，但不进入本版体验与评分。

## 操作与体验

- 启动直接进入引导学习，检查夹内切换三个自主检查情境。没有首页大面板或拿取时自动弹窗。
- 左摇杆连续行走，右摇杆30度分段转向；行走速度1.1米/秒。墙、设备和台面具有碰撞。
- 左X按需打开/收起实体检查夹；支持右手柄前端触碰或射线点击翻页。阅读时仍可行走，本版不提供传送开关。
- 引导学习使用地面路线、物件轮廓、局部操作提示和短暂手部示范；移除常驻腕部任务卡。自主检查不显示目标指引或预先透露答案。
- 按甲方六组顺序检查隔断/设备分设/工序、工具/毛刷、供水/滤膜维护、消毒产品、附件、测漏设备/登记。
- 固定检查对象需要走近才能打开。可移动物品只接受近距离侧握抓取，持物按扳机查看完整资料；松手返回工位。
- 附件盒盖可以开合，打开后才能拿取包装查看标识。
- 打开资料不计完成；教学通过持续近看或持物转动推进，文件需翻完全部页面再收起。自主检查按右A记录正常，右B选择问题原因后按A确认。教学按顺序推进，自主检查可自由选择。
- 最终在房间入口旁的记录台汇总或提交，评分仅包含本房间11项。

## 验证边界

代码和自动化可检查目录范围、路线可达、场景加载、资料页不自动完成、碰撞阻挡和评分。桌面截图不证明Quest佩戴效果；头显字号、移动舒适度、近距离抓取和实际帧率仍需实测。

此版是监督检查互动，不包含刷洗、配液或完整临床洗消操作模拟。现有清洗室模型保留；检查夹、容器和材质已采用网络资源，专用工具与包装仍有简化模型。当前使用Touch手柄，未接入裸手追踪。详见[本轮交互](FIRST_HAND_INTERACTION.md)和[资源许可](WEB_ASSET_SOURCES.md)。
